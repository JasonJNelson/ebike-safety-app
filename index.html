E-Bike Classes Explained

Class 1

Assist up to 20 mph

Pedal-assist only. Widest trail & path access.

Class 2

Assist up to 20 mph

Throttle + pedal-assist. Some path restrictions.

Class 3

Assist up to 28 mph

Pedal-assist only (higher speed). Often road/bike-lane only.

Park & Street Rules (General)

  • Public Streets & Bike Lanes
    Most states treat Class 1–3 like bicycles. Follow traffic laws.
  • Sidewalks
    Generally prohibited unless local law allows.
  • Multi-Use Paths & Trails
    Class 1 broadest access; Class 2/3 more restricted.
  • National Parks (NPS)
    Allowed where traditional bikes are permitted.
  • Federal Lands
    BLM generally allows Class 1–3; Forest Service often treats as motorized.
  • Local Override
    Cities can be stricter (e.g. NYC 15 mph cap).
