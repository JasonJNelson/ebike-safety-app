E-Bike Classes Explained

Class 1

Assist up to 20 mph

Pedal-assist only. Widest trail and path access.

Class 2

Assist up to 20 mph

Throttle + pedal-assist. Some path restrictions.

Class 3

Assist up to 28 mph

Pedal-assist only at higher speed. Often road / bike-lane only.

Park & Street Rules (General)

  • Public streets & bike lanes
    Most states treat Class 1–3 like bicycles. Follow traffic laws.
  • Sidewalks
    Generally prohibited unless local law allows.
  • Multi-use paths
    Class 1 usually has the broadest access; Class 2/3 more restricted.
  • National Parks
    Allowed where traditional bikes are permitted.
  • Federal lands
    BLM often allows Class 1–3; Forest Service may treat e-bikes as motorized.
  • Local override
    Cities can be stricter (for example NYC 15 mph cap).
